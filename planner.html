    Under the hood

    How it
    works

    The planner is written in plain JavaScript in js/planner.js.

    1. Every task is an object held in one JavaScript array. The list on screen is redrawn from that array whenever it changes.
    2. Adding, completing and deleting are separate functions, each triggered by its own event listener.
    3. The counters, progress bar and filters all read from the same array, so they can never disagree.
    4. After every change the array is saved to localStorage and read back when the page loads.
